# Site Machine

## Who is it for?
Site machine is a static website builder mainly intended for those who do not know HTML or CSS.
The point is to allow people to use the creator.html page (or their own custom one) to create and build websites or web pages in a google sites style.

## How does it work?
Site machine builds websites and web pages by reading JSON (/JavaScript objects) and building pre-existing or custom components based on what the content contains.

## Why should you use site machine?
If you wish to create websites visually or wish to let your users create their own profile pages with components, this package might reduce your workload by providing what's needed.
